    Two pages are missing the tag. A lead that happens on one of them is invisible to Results, so the coverage figure is worth more attention than the event count.

    The three events

    Page view Every page. This is the base tag and the retargeting pool.
    Lead Only the page that confirms the action — a thank-you, a booking, a quote request. Not the form itself.
    Purchase Only the order confirmation, with the order value. This is what makes cost per purchase and return on spend possible.

    A purchase event that fires on every page is the commonest install error and it silently multiplies your reported revenue. We check for it and flag it within a day.
